Editor de mapes

Amb PenguinRunner, hem inclós un editor de mapes que pots emprar per crear o editar-los, per obrir-lo cal executar el joc amb el parametre -editor (java -jar ./PenguinRunner.jar -editor)

Amb aquesta eina, podràs crear els teus mapes personalitzats com vulguis.
