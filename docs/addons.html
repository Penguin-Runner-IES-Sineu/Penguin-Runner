Documentació oficial del joc. Controla un pingüí, recull gelats i supera nivells.

Descripció General Add-ons (Games i Mods)

Estructura de càrrega (game)

Per carregar contingut dins el joc, cal crear una carpeta amb la següent estructura dins la carpeta games/ al costat del .jar.:

📁 games/
📁 game/
📁 sprites
font.ttf→ Fontprincipal del joc
emoji.ttf→ Fontd'emojis (recomanat: Segoe UI Emoji)
music.wav→ Músicadel joc
maps.json→Definició dels mapes
printables.json→Definició desl sprites
⚠️ Les carpetes games i mods són OBLIGATÒRIES!

Estructura dels mods

Un mod s'ubica dins la carpeta mods.

📁 mods/
📁 el_meu_mod/
mod.json→ Definiciódel mod
image.png→ Spritepersonalitzat
music.wav→ Música oSFX

Camps de mod.json

modtype spritemapsfxmusicfont
modvalue Objecte JSON amb el format corresponent al tipus (map, sprite, sfx,music, font)

Tipus de modvalue per cada modtype

map Objecte map amb camps: type level view
sprite Objecte sprite amb camps: type sprite color filename
sfx Només té el camp type - el tipus de so(e.g. icecream per al so en recollir unobjecte)
music Només té el camp music - per a la música de fons del joc
font Camp type - especifica si és una fontd'emoji o de text 
[
{
"modtype": "map",
"modvalue": {
"type": "map",
"level": "map",
"view": 5,
"###############################",
"#..D..D...D....................#",
"#.....P.....L..................#",
"###############################"
]
}
},
{
"modtype": "sprite",
"modvalue": {
  "type": "player",
  "sprite": "🙂",
  "color": "#FFFF00",
  "filename": "image.png
}
}
]
>ℹ️ Tots els filename seran relatius a la carpeta on està ubicat el mod.json.

Estructura dels mapes (maps.json)

Els mapes es defineixen en format JSON amb la següent estructura. Totes les files han de tenir la mateixa longitud.

[
{
"type": "map",
"level": 0,
"view": [
"###############################",
"#.....D...G.......P............#,
"###############################"
]
  }
]

Camps

type Sempre "map"
level Número del nivell (defineix l'ordre d'aparició)
view Array de strings amb la representació visual del mapa

Llegenda dels mapes

Símbol Significat
# Paret indestructible
. Bloc de gel
G Gelat 🍦
H Escala
- Rail / passarel·la
D Porta
S Pedra movible
P Jugador (posició inicial) 🐧
E,A, S Enemics
F Lanzallamas
B Botó
b Bloc Trampilla: apareix o desapareix quan pitges un botó
Espai buit
06 - Sprites

Estructura dels sprites (printables.json)

[
{
"type": "door",
"sprite": "🚪",
"color": "#FF00BB",

]

Camps

type Tipus de bloc (veure llista)
sprite Emoji o caràcter alternatiu (usat si no hi ha imatge)
color Color en format hexadecimal (e.g. #FF00BB)
filename Nom del fitxer dins la carpeta /sprites

08 - Addicional

Notes addicionals

🖼️ Si no es troba una imatge per a un sprite, es pot utilitzar un emoji com a alternativa.
🔤 Es recomana no canviar la font d'emojis si no és necessari.
🗺️ Els mapes es poden crear manualment amb eines com asciistudio.
⚠️ Les carpetes games i mods han d'existir obligatòriament al costat del fitxer .jar.
