Com carregar mods i games?

Per carregar un mod, s'ha d'executar el .jar amb el parametre -m o -mod seguit del nom de la carpeta que es vol carregar, per exemple "-m yaris"

Per carregar un game, segueix la mateixa nomenclatura, però amb -g o -game, i el contingut a la carpeta games

L'ordre de carrega recomanat és -game -mod -mod -mod..., ja que un game re-emplaçarà TOT el contingut del joc quan es carregui, per tant si pos -mod -mod -game, el -game ho sobre-escriurà tot

Estructura de càrrega (game)

Per carregar contingut dins el joc, cal crear una carpeta amb la següent estructura dins la carpeta games/ al costat del .jar.:

📁 games/
📁 game/
📁 sprites
font.ttf→ Font principal del joc
emoji.ttf→Font d'emojis (recomanat: Segoe UI Emoji)
music.wav→Música del joc
maps.json→Definició dels mapes
printables.json→Definició dels sprites
collect.wavSo al recollir un gelat
door.wavSo al pasar per una porta
pickup.wavSo al agafar un objecte
flame.wavSo al emprar el llançaflames
teleport.wavSo al teletransportar-se
death.wavSo al morir
gameover.wavSo al perdre el joc
⚠️ La carpeta games es obligatòria per a la carrega del joc!

Estructura dels mods

Un mod s'ubica dins la carpeta mods.

📁 mods/
📁 el_meu_mod/
mod.json→Definició del mod
image.png→Sprite personalitzat
music.wav→ Música de fons
collect.wav→ SFX per recollida d'un objecte

Camps de mod.json

modtype: el tipus d'objecte Pot ser: sprite map sfx musicfont
modvalue Objecte JSON amb el format corresponent al tipus (map, sprite, sfx,music, font)

Tipus de modvalue per cada modtype

map Objecte map amb camps: type level view
sprite Objecte sprite amb camps: type sprite color filename
sfx, music, font Tenen dos camps: type i filename Filename: ruta a l'objecte que s'està afegint Type: el subtipus d'objecte que s'està afegint, té uns certs tipus: music musica de fons (només emprat amb field music) text indica que es una font de text (només emprat amb field font) emoji indica que es una font de emojis (només emprat amb field font) collect agafar un gelat flame emprar llançaflames pickup agafar un objecte teleport emprar el teleport door entrar per una porta death un enemic te fer gameover mors i perds el joc

Estructura dels mapes (maps.json)

Els mapes es defineixen en format JSON amb la següent estructura. Totes les files han de tenir la mateixa longitud.

    {
        "type": "map",
        "level": 2,
        "view": [
            "###############################",
            "#                             #",
            "#     A     H------D A        #",
            "#     ......H      ...        #",
            "#   H G     H                 #",
            "#   H.........                #",
            "#T  H    P     EEEE           #",
            "#.............................#",
            "###############################"
        ]
    }

Camps

type (sempre serà map)
level Número del nivell (defineix l'ordre d'aparició)
view Array de strings amb la representació visual del mapa

Llegenda dels mapes

Notes addicionals

🖼️ Si no es troba una imatge per a un sprite, es pot utilitzar un emoji com a alternativa.
🔤 Es recomana no canviar la font d'emojis si no és necessari.L'única font d'emoji provada funcional ha estat Segoe UI Emoji
🗺️ Els mapes es poden crear manualment amb eines com asciistudio.
Blocs adaptatius

El joc pot carregar blocs adaptatius per els blocs de gel, en cas de que se proporcionin tots els blocs necessaris.

Per saber quins son els blocs necessaris, descarregar el "full_game" del github, i mirar dins la carpeta games/ices, la carpeta sprites conté tots els arxius i printables té totes les definicions, això si, s'ha de mantenir el nom com està, amb el prefixe de ice_
