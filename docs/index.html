01 - Introducció

Descripció general

PenguinRunner és un joc en el qual controles un pingüí mitjançant el teclat. L'objectiu principal és recollir tot els gelats d'un nivell per desbloquejar una porta que et permetrà avaçar al següent nivell.

02 - Input

Controls del jugador

Moviment

↑↓←→
WASD

Fletxes del teclat o tecles WASD per moure el pingüí.

Habilitats

QE

Trencar blocs adjacents al judador.

03 - Gameplay

Mecàniques del joc

  • 🐧 El jugador controla un pingüí.
  • 💥 El pingüí pot destruir blocs propers amb les tecles Q i E.
  • 🍦 S'han de recollir tots els gelats del mapa.
  • 🚪 Quan es recullen tots els gelats, s'activa una porta.
  • ➡️ Les portes permeten accedir a altres nivells.

05 - Mapes

Estructura dels mapes (maps.json)

Els mapes es defineixen en format JSON amb la següent estructura. Totes les files han de tenir la mateixa longitud.

[
        {
            "type": "map",
            "level": 0,
            "view": [
                "###############################",
                "#.....D...G.......P............#,
                "###############################"
            ]
          }
        ]

Camps

type Sempre "map"
level Número del nivell (defineix l'ordre d'aparició)
view Array de strings amb la representació visual del mapa

Llegenda dels mapes

Símbol Significat
# Paret indestructible
. Bloc de gel
G Gelat 🍦
H Escala
- Rail / passarel·la
D Porta
S Pedra movible

E, A, S Enemics
F Lanzallamas
B Botó

Espai buit

07 - Modding

Estructura dels mods

Un mod s'ubica dins la carpeta mod.json.

📁 mods/
📁 el_meu_mod/
mod.json→ Definició del mod
image.png→ Sprite personalitzat
music.wav→ Música o SFX

Camps de mod.json

modtype sprite map sfx music font
modvalue Objecte JSON amb el format corresponent al tipus (map, sprite, sfx, music, font)

Tipus de modvalue per cada modtype

map Objecte map amb camps: typelevelview
sprite Objecte sprite amb camps: typespritecolorfilename
sfx Només té el camp type - el tipus de so (e.g. icecream per al so en recollir un objecte)
music Només té el camp music - per a la música de fons del joc
font Camp type - especifica si és una font d'emoji o de text 
[
        {
            "modtype": "map",
            "modvalue": {
                "type": "map",
                "level": "map",
                "view": 5,
                    "###############################",
                    "#..D..D...D....................#",
                    "#.....P.....L..................#",
                    "###############################"
                ]
            }
        },
        {
            "modtype": "sprite",
            "modvalue": {
              "type": "player",
              "sprite": "🙂",
              "color": "#FFFF00",
              "filename": "image.png
            }
        }
    ]
>ℹ️ Tots els filename seran relatius a la carpeta on està ubicat el mod.json.
